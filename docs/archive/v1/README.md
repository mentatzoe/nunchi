# V1 design archive

These documents preserve product-facing contracts, data models, and
quickstarts that originally lived inside retired SpecKit features `001` and
`002`. They describe the historical TurnAware naming and early V1 behavior.

They are not current instructions, product contracts, or planning authority.
Current implementation is documented by the repository `README.md` and
`docs/STABILITY.md`; the architecture goal and gaps are in `AGENTS.md`.
`contracts/` holds the retired V1 channel-adapter and verdict-suite contracts.
